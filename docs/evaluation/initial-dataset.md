# Initial Evaluation Dataset

`evaluation/baseline_questions.json` provides 102 grounded Persian cases across lookup, filtering, aggregation, grouping, ranking, top-N, date/time, comparison, follow-up, ambiguity and edge cases. This document's machine-readable 25-question smoke dataset is `docs/evaluation/initial-dataset.json`; representative cases include q001 COUNT Orders, q006 Shipments.typeName, q007 year/status filter, q015 grouped quantity with unit caveat, q017 revenue quantity*unitPrice, q018 average per-order line count, q019 triple-join netWeight, q023 operationMonth monthly sales, q030 largest order, q041 MIN/MAX date, q046 impossible year empty result and q048 year comparison. Full JSON is normative; unresolved domestic/export and similar fuzzy definitions remain unresolved rather than guessed.
